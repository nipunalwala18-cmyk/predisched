Setup and controls

  • Every run starts a fresh cluster of real processes on one laptop (Intel i5-8350U, 4 cores / 8 threads, 15 W): one scheduler (configs/benchmark-node.yaml, PostgreSQL history on, result cache off, speculation off) and three workers. The prediction server and the mock HTTP target run for the whole suite.
  • Each scenario replays one saved trace from workloads/benchmark, identical for every strategy and repetition (SHA-256 checked before every run). Trace seeds were used neither for the training dataset nor for λ tuning.
  • Repetition-major order with the strategy order rotated each repetition, so machine drift spreads over strategies.
  • The first 10 % of each trace's tasks are excluded from the latency percentiles (warm-up). Every task carries a 2000 ms deadline; SLA violation = failed or later than that.
  • Latency is submit → completion as seen by the client (status polled every 50 ms).

Limitations

  • Everything runs on one 4-core laptop: workers share the CPU, so "heterogeneous" hardware is simulated with pool sizes and a slowdown factor, and the prediction server competes with the workers it predicts.
  • Five repetitions per cell: small differences can go undetected, and one test per metric and scenario is reported without a multiple-comparison correction.
  • The models were trained on one campaign (prompt 15) on this same machine; the queue-forecast model never beat its baseline, and the overload model's threshold did not transfer to the held-out pattern (docs/components/ml-models.md).
  • ML predictions can be wrong, and a poor model can make scheduling worse than a simple baseline; prediction calls add overhead to every decision (see above).
  • Historical data may not capture sudden, unseen spikes; workload patterns drift, so models need retraining (prompt 21).
  • New task types face a cold start (a type-average fallback); monitoring and heartbeats add their own overhead.
  • A single active scheduler is a throughput ceiling; these results say nothing about larger clusters.
